# NASA DEVELOP 2026

**NASA DEVELOP National Program | Project Repository**

## Project Overview

This repository contains the source files, analytical workflows, and supporting materials for the NASA DEVELOP 2026 project.

The project uses R, Quarto, and Reveal.js to develop and communicate research findings through a reproducible analytical workflow and interactive presentation.

## Reproducibility

The presentation source is maintained in Quarto (`.qmd`) format. Supporting scripts and project resources are organized within the repository.

To reproduce the presentation, open the project in RStudio and render the Quarto document.

```r
quarto::quarto_render("revealjsNASA_2026.qmd")
```
Slide shows for 2024/2025 are old versions and do not display (photos/here links not set) but available for download if desired.
